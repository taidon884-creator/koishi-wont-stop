## どんなゲームか

古明地こいしは、目の前に何があっても止まりません。
プレイヤーは、お空とお燐を切りかえながら、こいしが歩き出す前に道の罠を片づけます。

- こいしが通るルートが見えるのは、ステージの最初だけ
- **お空**：敵をたおす／針の穴の上を飛ぶ／木箱を押す
- **お燐**：死体を猫車で運ぶ／まわりの動く敵を止める／木箱を押す
- 片づけ忘れると、こいしが激突・落下してやり直し

### 収録内容

- 全15ステージ（チュートリアル〜ルナティック。後半は最短でも50手以上）
- ノーマルモード／チャレンジモード（準備中でもこいしが勝手に出発する）
- ステージエディタと、作ったステージを英数字の「ステージコード」で交換する機能
- ストーリー会話、エンディング

## 技術的な特徴

### ゲームエンジンを使わず、C++ と Windows API だけで制作

| 用途 | 使用技術 |
| --- | --- |
| 言語 | C++20 |
| 描画 | Direct2D / DirectWrite（論理解像度 1280×720 で描き、ウィンドウに合わせて拡大） |
| サウンド | XAudio2 |
| 画像入出力 | WIC |
| 動画書き出し（開発用） | Media Foundation（H.264 / AAC） |
| ビルド | Visual Studio / MSBuild（Debug・Release・体験版の3構成） |

外部ライブラリ・外部素材ファイルは使っていません。配布物は exe ひとつで動きます。

### 素材をすべてプログラムで生成

- **ドット絵**：キャラクター・タイル・UI のドット絵を、コード内のデータから起動時に生成
- **BGM・効果音**：起動時にプログラムで波形を合成
- `assets` フォルダに PNG を置くと差し替えられる仕組みも用意し、絵の調整をしやすくしました

### ゲームルールと描画の分離

ルール部分（`World`）は、描画を持たない独立したクラスにしました。
同じ `World` を、ゲーム本編・ステージエディタのテストプレイ・自動テスト・解探索ツールのすべてで使っているため、
「テストでは通るのに、ゲームでは動きがちがう」ということが起きない作りになっています。

### ステージの品質を守る開発ツール

パズルゲームで一番こわいのは「解けないステージ」を出してしまうことです。そのために、次のツールを自作しました。

- **セルフテスト（`--selftest`）**
  全ステージの解答手順をゲームと同じ速さで実行し、クリアできるかを自動で確認。変更のたびに実行し、失敗数を返します。
- **最短手数ソルバー**
  幅優先探索でステージの最短手順を求めます。ON/OFF スイッチ・一方通行などの状態も含めて探索します。
- **時間まで含めたソルバー**
  ゲームと同じ計算を 1/120 秒ずつ進めて探索するため、動く敵がいるステージや「こいしが歩いている間にスイッチを切りかえる」といった手も確認できます。
  見つけた手順は、最後に本物のゲームロジックで再生してクリアできることを確かめてから返します（誤って「解ける」と判定しない）。
- **ステージ自動生成（`--gen`）**
  マルチスレッドでランダムにマップを作り、最短手数が長い（＝歯ごたえのある）候補を探します。ステージ制作の下書きに使いました。

### ステージコード

エディタで作ったステージを、人に渡せる短い英数字（例：`4KQ2M-7ZP0C-…`）に変換します。

- 読みまちがえやすい文字（I・L・O・U）を除いた32文字だけを使用
- 小文字・全角・ハイフン・空白が混ざっても読める
- 検査用の数字を入れ、打ちまちがいをほぼ検出
- 読みこみ時に「キャラが1人ずつ」「ルートがゴールに着く」などを検証し、遊べないステージを弾く

### 宣伝用の映像を、ゲーム自体から書き出す

紹介映像・YouTube ショートは、ゲームに組みこんだ撮影モード（Debug ビルドのみ）で作りました。

- 固定時間刻みでゲームを進め、1コマずつ画面を取りこんで 60fps の動画に書き出す
- 音はリアルタイム再生ではなく、効果音・BGM をその場で合成して映像と完全に同期
- 横動画（1280×720）と縦のショート動画（1080×1920）を、台本（タイムライン）のコードから自動生成
- 製品版・体験版それぞれの素材を同じ仕組みで出力

手作業の動画編集をせずに、ゲームを修正したらすぐ映像も作り直せる状態にしています。

### 配布まわり

- セーブデータは exe と同じ階層の `SaveData` フォルダにまとめ、フォルダを移すだけで体験版から製品版へ引き継げる設計
  （書きこめない場所に置かれた場合は、ドキュメントフォルダへ自動で切りかえ）
- 体験版はビルド構成（`TRIAL_VERSION`）で切りかえ、製品版のステージを体験版の exe に含めない
- exe にバージョン情報を埋めこみ、タイトル画面にもバージョンを表示

## 生成AIの利用について

本作は、生成AI（Claude Code）を開発に利用しています。
プログラム・ドット絵・BGM・効果音の作成に AI を使い、
企画・ゲームの仕様・ストーリー・ステージの難易度調整・品質の確認は人が担当しました。

AI に任せきりにせず、

1. 仕様をことばで細かく決めて指示する
2. セルフテストやソルバーで、出来上がったものを機械的に検証する
3. 実際に遊んで、手ざわりや難しさを調整する

という流れで品質を保つことを意識しました。
